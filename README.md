## Implementation status
The repository currently contains the Figma prototype link only. The production implementation is not generated yet because the Figma canvas/prototype could not be accessed by the available reader, so exact visual parity cannot be validated.

## Target architecture
- Frontend: React + Vite
- Backend: Node.js + Express
- Database: PostgreSQL + Prisma
- Contact form API with validation
- Environment variables for database and email credentials
- Backend integration must not alter the visual design

## Figma parity requirements
Do not change:
- layout and spacing
- buttons and button states
- typography/fonts
- colors
- borders, shadows and corner radii
- images and icons
- responsive structure
- hover and transition behavior represented in the prototype
